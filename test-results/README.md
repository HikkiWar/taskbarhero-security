# test-results — материалы по уязвимостям TaskBarHero

Результаты тестирования от **2026-07-26**. Всё локально: собственный аккаунт,
сейв и клиент. Изменения характеристик и рун откачены, целостность проверена.

## Что где

| Файл | Что это |
|---|---|
| `FINDINGS.md` | **основной документ** — находки, цифры, методика, рекомендации |
| `tbh-security-report.html` | отчёт для вендора (английский, пароль зашифрован) |
| `poc/` | по одному скрипту на находку, все поверх общего `core.py` |


## poc/

| Скрипт | Находка |
|---|---|
| `core.py` | общее ядро: ES3, память, поиск объектов (то же, что в демо-утилите) |
| `f01_negative_price.py` | **F-01** отрицательная цена начисляет золото |
| `f02_attributes_runes.py` | **F-02/F-03/F-05** характеристики, руны, бюджет очков |
| `f04_combat_stats.py` | **F-04** боевые статы, множитель опыта, ХП мобов |
| `f06_es3_crypto.py` | **F-06** расшифровка сейва, байт-точная сериализация |
| `control_protected.py` | контрольная группа: что защита отбивает |

Требуется Python 3, `pycryptodome` и `numpy`. Игра должна быть запущена.

```bash
pip install pycryptodome numpy
```

## Быстрый старт

```bash
python poc/f06_es3_crypto.py verify        доказать байт-точность сериализации
python poc/f04_combat_stats.py heroes      найти блоки всех героев (~3 с)
python poc/f01_negative_price.py show      таблица цен рун
python poc/control_protected.py gold       показать, что защита работает
```

Начинать показ лучше с `control_protected.py` — он демонстрирует, что механизм
у разработчика есть и работает. На этом фоне остальные находки читаются как
точечный пропуск, а не как «всё сломано».

## Методика проверки

Единственный корректный способ подтвердить находку — **дождаться автосейва самой
игры**, а не читать файл сразу после записи. Ранние прогоны давали ложные «PASS»
именно потому, что перечитывали собственную запись раньше, чем игра успевала
сохраниться.

Протокол: правка памяти → ждать автосейв (~3 мин) → расшифровать сейв →
полный рестарт → перечитать. Значение, пережившее рестарт, прошло синхронизацию
с сервером.
